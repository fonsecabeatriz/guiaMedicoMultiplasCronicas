# Guia de Médicos MC

Site do Guia de Médicos da comunidade Múltiplas Crônicas.

## Rodar
- Dê dois cliques em `iniciar.bat` (usa o Node se estiver instalado; se não, usa o PowerShell do Windows), **ou**
- No terminal, dentro da pasta: `npm start`

Abra http://localhost:3000. Para parar, feche a janela do terminal (ou Ctrl+C).

## Editar a lista
Os profissionais ficam em `docs/medicos.js`. Salve e recarregue a página.

## Publicar no GitHub Pages
O site fica na pasta `docs`. No repositório: Settings → Pages → Build and deployment →
Source: "Deploy from a branch", Branch: `main`, pasta `/docs` → Save.
